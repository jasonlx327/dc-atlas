# IDC Atlas 产业链信息网 · 产品经理评审与设计方案

评审对象：当前平面原型（v0.12，左→右默认）、3D 原型、功能规格、模拟数据（50 实体 / 108 关系）。
评审视角：用户友好性。核心原则：证据导向、未披露不估算、媒体值标「媒体」、atlas-cover 编辑气质、双语。

## 1. 目标用户与核心任务

- 用户：中美投资人与产业从业者，习惯「公司 → 关系 → 数字 → 来源」的查询路径。
- 核心任务：
  1. 从一家公司看上下游关系（最常用）。
  2. 看某一链路全景（HBM / 液冷 / 电力 / 租赁 / 存储 / 国产算力）。
  3. 查一笔具体关系的金额、时间与来源可信度（验证）。
  4. 跟踪变化（新边、状态推进、金额披露率上升）。

## 2. 当前原型的评估

做得好的：证据分层、金额披露率、未披露不估算、场景入口、路径与传导分析、分类聚合视图、左→右方向感、悬停/放大显示标签、实体关键披露栏。
主要问题：
- P0 认知负担：工具栏 20+ 按钮平铺，首次用户不知道从哪开始；「场景/布局/来源/数据/路径/聚合/邻居边/完整/时间轴/搜索/导出/分享/对比/传导/关注」层级不清，很多是功能堆叠而非用户任务。
- P0 默认视图不传达产品意图：图上没有一句话说明「这是什么、上游左下游右、怎么展开」；用户第一眼把图当装饰。
- P1 关键数据被交互藏住：用户最想要的「金额、日期、来源层级」在图上默认不可见（要悬停），卡片区有但图上看不到，图与卡片两张皮。
- P1 入口与站点割裂：没有设计从公司档案页 / 专栏 / 首页进入的路径；`/industry-network` 作为独立页没有上下文。
- P1 移动端是缩小的桌面图，不是移动体验。
- P2 双语缺失；P2 无首次引导；P2 3D 炫技 > 有用（用户已否）。

## 3. 信息架构建议

- 一层入口：公司档案页内嵌「上下游关系」板块（主入口，SEO 友好）；独立总览页保留但弱化为「看全链路」入口。
- 一层任务：场景入口（HBM/液冷/电力/租赁/存储/国产）作为总览页顶部导航，不是工具栏按钮。
- 页面结构（从上到下）：
  1. 公司名 + 一句说明（如「英伟达的上下游公开关系，来源可追溯」）。
  2. 分类聚合图（默认）：聚焦公司居中，左侧上游分类、右侧下游分类，点击分类展开成员。
  3. 图下方/右侧：当前聚焦公司的上下游卡片列表（已有），数字优先。
  4. 页脚：数据口径、最后更新时间、金额披露率、来源层级图例。
- 工具栏收敛为三组（可折叠）：
  - 视图：布局（左→右/上→下/力导向/径向）、聚合开关。
  - 数据：来源（官方/管理层/媒体）、金额（有金额/仅官方）、时间轴。
  - 工具：路径查询、双公司对比、传导分析、导出/分享、关注。
  默认只展示第一组，其余收进「更多」。

## 4. 默认体验设计（用户打开第一眼）

- 第一眼 = 公司 + 5~6 个分类聚合节点 + 一条引导条：「上游在左 · 下游在右 · 点击分类展开 · 点击边看证据」。
- 第二步引导（首次 3 条气泡，可关闭）：点分类看成员；点边看金额与来源；点公司设聚焦。
- 数字优先原则：展开后，边显示「关系类型 + 金额（有则显示）」徽标；公司名与 ticker 在节点内/悬停，避免标签堆叠。
- 图与卡片联动：点击图中节点/边，右侧卡片区同步高亮对应关系；避免图是图、卡是卡。

## 5. 交互优化清单

P0（先做）：
- 默认视图收敛：分类聚合 + 左→右 + 仅聚焦直接边，删掉默认展示的「邻居边/完整/分组圈选」入口（保留功能，收进更多）。
- 首次引导条 + 3 条气泡。
- 图与卡片联动高亮。
- 工具栏三组折叠。
P1（第二版）：
- 数字优先徽标（金额/日期默认可见，悬停才显示公司名标签）。
- 从公司档案页进入的入口设计（/companies/[slug] 内嵌板块）。
- 移动端改版：默认卡片列表 +「查看图谱」全屏入口。
- 英文核心字段（公司名、关系、金额、来源链接）。
P2（后续）：
- 3D 仅作彩蛋，不进默认路径。
- 变化通知（关注公司的边新增/状态推进）。
- 分享链接带时间轴与路径状态（已具备基础）。

## 6. 移动端策略

- 390px 默认 = 上下游卡片列表（上游一组、下游一组），数字与来源直接可见。
- 图作为「查看图谱」全屏页面，简化交互：只保留点击节点看详情、点边看证据、布局固定左→右。
- 移除小屏上的路径/对比/传导（放桌面版与「更多」）。

## 7. 双语策略

- 不做全量翻译。英文版覆盖：公司名/ticker、关系类型、金额与单位、来源链接、证据层级标签、状态阶梯。
- 页面骨架文案（引导、口径说明）随语言切换。

## 8. 数据与信任设计

- 保留现有：金额披露率、未披露（不估算）、官方/管理层/媒体标签、来源链接。
- 补充：页面统一「数据口径」一行（如「金额仅展示已披露值 · 未披露不估算 · 每日更新」）；每条边显示观察日期与最后核验时间（已有，需在图上可见）。
- 生产版：金额与状态由 watch 管线每日入库，披露率随时间上升，页面显示「上次更新」时间戳。

## 9. 落地路线

- MVP（第一版正式）：公司档案内嵌板块 + 分类聚合图（左→右）+ 边证据抽屉 + 场景入口 + 金额披露 + 图卡联动。
- 二期：路径查询、双公司对比、传导分析、时间轴、关注通知。
- 三期：英文版、移动端全屏图谱、3D 彩蛋。

## 结论：对用户最友好的 3 个关键决策

1. 入口从「公司档案」进入，图是探索工具而不是炫技首页，第一眼是「公司 + 分类骨架 + 一句引导」。
2. 工具栏分组折叠、功能收进「更多」，默认视图只保留最高价值信息，密度交给用户主动展开。
3. 数据优先于交互：金额/日期/证据层级默认可见，悬停与展开只用于看更多，不要求用户先交互才能看到数据。
