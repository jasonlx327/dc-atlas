# Open-source scope

The files tracked in this public repository are released under the
[Apache License 2.0](LICENSE), unless a file states otherwise.

The public distribution intentionally does not include:

- private administrative consoles and internal operator tools;
- credentials, access policies, service tokens, or environment values;
- unpublished editorial queues, research drafts, or internal datasets;
- private deployment and operational automation that is not present here.

Those materials are separate from this repository and are not licensed by this
repository's Apache-2.0 license. Public configuration examples must contain
placeholders only and must never include working credentials.

IDC Atlas names, logos, and visual identity are not granted for use as a
trademark by the Apache-2.0 license.
